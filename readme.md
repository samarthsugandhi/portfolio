## ✦ About

A handcrafted, production-grade developer portfolio built with **Three.js**, **GSAP**, and **React** — featuring real-time 3D WebGL rendering, GPU-accelerated animations, and a working contact system backed by an Express server.

> *"Real systems, not side projects."*

---

## ⚡ Tech Stack

| Layer | Technology |
|---|---|
| 3D Rendering | Three.js (r137) + GLSL Shaders |
| Animations | GSAP 3 + Framer Motion + Tween.js |
| UI Framework | React 17 + TypeScript |
| Camera System | camera-controls |
| Bundler | Webpack 5 (custom dev + prod config) |
| Server | Express.js + Nodemailer (contact form) |
| Deployment | Vercel |

---

## ✦ Key Features

- **Real-Time 3D WebGL Scene** — Three.js environment with custom GLSL shaders, GPU-driven geometry, and interactive camera controls
- **GSAP Scroll Animations** — timeline-based entrance transitions and scroll-triggered reveals throughout every section
- **Working Contact Form** — Express backend with Nodemailer handles email delivery directly from the site
- **Custom Webpack Pipeline** — separate dev and production configs with code splitting, compression, and full asset optimisation
- **TypeScript Throughout** — fully typed codebase across React components and Three.js scene logic
- **Responsive Design** — adapts cleanly across mobile, tablet, and desktop viewports

## 🛠️ Local Setup

```bash
# Clone the repository
git clone https://github.com/samarthsugandhi/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🚀 Production Build

```bash
# Build for production (Webpack bundles + optimises assets)
npm run build

# Start the Express production server
npm start
```
